# Phrase Bank

上課、跟同學聊天、coffee chat 和面試用得到的英文句子。

單一 `index.html`，不用安裝，直接用瀏覽器打開即可。

## 功能

- **單字卡**：點卡片翻面，可切換先看中文或英文，方向鍵切換卡片，空白鍵翻面
- **學習**：隨機出題，自己判斷「記得了 / 還不熟」，會更新學習進度
- **測驗**：中翻英四選一，結束後列出答錯的題目
- 搜尋、語氣篩選（casual / neutral / formal）、收藏、只看還不熟的
- 朗讀英文（瀏覽器內建語音）、一鍵複製
- 自己新增句子
- 深色模式

收藏、學習進度和自己新增的句子存在瀏覽器的 localStorage。

## 用 GitHub Pages 發佈

Settings → Pages → Source 選 `main` branch、`/ (root)`，存檔後就會有網址。
